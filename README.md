# Avenue Business Services - الموقع الرسمي (Landing Page)

موقع صفحة هبوط احترافية متكاملة لشركة **أڤينيو لخدمات الأعمال (Avenue Business Services)** تحت إدارة **أ. حسام نبيل عبدالخالق (المدير العام)**.

---

## 🌟 مميزات الموقع

1. **تصميم عصري متجاوب بالكامل (Responsive RTL)**:
   - مستوحى بالكامل من الهوية البصرية لكارت الشركة (الأزرق الملكي `#0e3b64`، البرتقالي الحيوي `#e04e1a`، والأبيض الصافي).
   - متوافق 100% مع جميع الهواتف الذكية (iOS و Android)، التابلت، وشاشات الحواسيب المكتبية والشاشات العريضة.

2. **أنيميشن ومؤثرات بصرية سلسة (Modern Animations)**:
   - أنيميشن ظهور سلس عند التمرير (Scroll-Driven Animations & IntersectionObserver).
   - بطاقة أعمال تفاعلية ثلاثية الأبعاد (3D Floating Card) في الواجهة الرئيسية مع تأثير التحويم والحركة.
   - عدادات رقمية متحركة للإحصائيات (أكثر من 500 شركة، 100% نسبة نجاح، 15 عاماً خبرة، فرعان رئيسيان).
   - أكورديون أسئلة شائعة متحرك وسريع الاستجابة.

3. **عنصر الواتساب الطائر المتقدم (Floating Interactive WhatsApp Widget)**:
   - زر عائم في زاوية الشاشة مع حلقات نبض مضيئة (Pulse Animation) ونقطة اتصال مباشرة خضراء.
   - تلميح تفاعلي لطيف يطفو لجذب انتباه الزائر: *"تحدث مع المستشار القانوني الآن 👋"*.
   - نافذة محادثة تفاعلية متطورة (Chat Drawer) تنبثق بنقرة واحدة تحتوي على:
     - هوية الشركة وصورة الشعار وحالة الاتصال *"عادة ما يتم الرد خلال دقائق"*.
     - رسالة ترحيب مخصصة من فريق أڤينيو.
     - 5 أزرار سريعة للاستفسارات الجاهزة (تأسيس شركة، إقرار ضريبي، فيزا شنجن، إقامة استثمارية، حجز موعد فرع).
     - حقل كتابة حر لنص العميل مع زر إرسال مباشر يحوّل الزائر فوراً لتطبيق واتساب مع رقم الشركة (`01009426680`).

4. **الأركان الأربعة الأساسية لخدمات الشركة**:
   - **تأسيس جميع أنواع الشركات** (ذات مسؤولية محدودة LLC، الشخص الواحد، مساهمة، منشآت فردية، فروع أجنبية).
   - **الإقرارات الضريبية والميزانيات** (إقرارات القيمة المضافة الشهرية، الميزانيات السنوية المعتمدة، الفاتورة الإلكترونية، الفحص الضريبي).
   - **تأشيرات دول الشنجن** (تجهيز الملف، حجز المواعيد VFS/TLS، حجوزات الطيران والفنادق المؤكدة، التأمين الدولي).
   - **الإقامات الاستثمارية للعرب والأجانب** (إقامات المستثمرين، تملك العقار، الودائع البنكية، تصاريح عمل المديرين).

5. **حاسبة تفاعلية للمتطلبات والخدمات (Interactive Calculator)**:
   - تتيح للعميل التبديل بين الخدمات واختيار نوع الكيان ليرى المستندات المطلوبة والمدة المتوقعة مع زر واتساب مخصص.

6. **فروع الشركة في القاهرة**:
   - **فرع روكسي - مصر الجديدة**: ٥ (أ) ش غرناطة، روكسي، مصر الجديدة (مع أزرار الاتصال والخرائط).
   - **فرع مدينة نصر**: ٩ ش الرياض من إسماعيل القباني، خلف جنينة مول، مدينة نصر.

7. **معاينة كارت العمل الأصلي وباركود QR Code**:
   - نافذة Modal منبثقة لمعاينة وتحميل صورة كارت العمل الأصلي.
   - كود QR Code مدمج بتقنية SVG يتيح المسح بكاميرا الهاتف للاتصال الفوري.

## 🚀 طريقة التشغيل

1. **التشغيل المباشر**:
   - انقر نقراً مزدوجاً على ملف `index.html` في مجلد المشروع، وسيفتح فوراً على أي متصفح (Google Chrome، Microsoft Edge، Safari، Firefox).
2. **التشغيل عبر خادم محلي (اختياري)**:
   - يمكنك فتح سطر الأوامر في مجلد المشروع وتشغيل:
     ```bash
     npx serve
     ```
     أو فتح المجلد في محرر VS Code أو Antigravity والضغط على **Go Live**.
